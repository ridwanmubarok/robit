## ROBIT v0.0.1

**Privacy-first local AI workspace.**

### Downloads
| Platform | File | Notes |
|---|---|---|
| Linux | `.AppImage` | Universal, portable |
| Linux | `.deb` | Debian/Ubuntu |
| Windows | `.msi` | Recommended |
| Windows | `.exe` | NSIS installer |
| Mac | `.dmg` | NSIS installer |

### First Run
The app will guide you through setup:
1. Download the AI Engine (Llama.cpp, ~30 MB)
2. Browse and import your `.gguf` model file
3. Start chatting locally — no cloud, no data sent out
